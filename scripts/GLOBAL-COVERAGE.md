of foods eaten widely elsewhere that it does not cover. Each batch below is a
research assignment: find real storage guidance from a credible source, then
write the record into `src/data/base/extra.json` using the schema in
`scripts/EXTRA-SPEC.md`.

Mark items done by moving them to the "Covered" note at the bottom of the batch.
Do not delete lines — a struck item with a note about why no source exists is
more useful than a silent gap.

## Rules for whoever works a batch

1. One credible source per item, in this order of preference: national food
   safety agency, university extension service, peer-reviewed literature, then
   an established industry or trade body. Fetch the URL; if it does not load or
   does not say what you want to cite, do not use it.
2. If no credible source exists for an item, use the closest FoodKeeper
   analogue, set `"analog"` to that slug, and say so in `notes`. Never present
   an analogue as a sourced figure.
3. Skip anything already in `src/data/base/foodkeeper.json` or
   `src/data/base/split.json`. Grep before writing.
4. Storage timelines are for the food as a home cook would store it, not
   industrial storage.
